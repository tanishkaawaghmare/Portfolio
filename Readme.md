Tanishka Waghmare - VLSI & Semiconductor Portfolio

This is a personal portfolio website for Tanishka Waghmare, a B.Tech (ENTC) student. It is designed to showcase academic highlights, skills, and personal information with a theme inspired by the VLSI and Semiconductor domain.

The portfolio is a clean, single-page application built with plain HTML and CSS.

🚀 Features

Single-Page Layout: All information is presented on a single, easy-to-navigate page.

VLSI-Inspired Theme: A modern, dark theme with cyan and gold accents, matching a blurred-circuit background to evoke a high-tech, semiconductor feel.

Responsive Sections: Includes an "About Me" and "Academic Highlights" section, plus a dedicated "Contact" area.

Self-Contained: All styling is included directly within the index.html file for simplicity.

🛠️ Tech Stack

HTML5: For the page structure and content.

CSS3: For all styling, fonts, and layout (using Flexbox).

🔧 Setup and Usage

To use this portfolio template:

Download the Files:
Make sure you have all the necessary files in one folder:

port.html (The main portfolio file)

chip-bg.png (The blurred background image)

profile.jpg (Your personal profile picture)

Open in Browser:
Simply double-click the index.html file to open it in any web browser.
